Politique de confidentialité

Balko ne collecte aucune donnée personnelle via ses outils gratuits. Les informations saisies dans le générateur de factures et de devis sont enregistrées uniquement dans le stockage local de votre navigateur (localStorage), sur votre appareil, pour vous éviter de les ressaisir. Elles ne sont jamais transmises à un serveur. Vous pouvez les effacer à tout moment en vidant les données du site dans votre navigateur.

Le site n'utilise pas de cookies publicitaires ni de traceurs.

Paiements

Les paiements sont traités par Stripe. Balko n'a jamais accès à vos coordonnées bancaires. Stripe nous transmet uniquement les informations nécessaires à la gestion de la commande (adresse e-mail, montant, date). Ces données sont conservées pendant la durée imposée par les obligations comptables (10 ans). Politique de Stripe : stripe.com/fr/privacy.
