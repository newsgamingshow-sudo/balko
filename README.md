# Balko
Outils gratuits pour micro-entrepreneurs (facture, devis, TJM) + Pack Pro payant.
- Construire le site : `python3 src/build.py` (génère `docs/`, servi par GitHub Pages)
- Générer le produit : `python3 produit/build_pack.py` (sortie dans `produit/dist/`, non versionnée)
- Pilotage : voir `business/STATE.md`
